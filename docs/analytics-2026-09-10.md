## 2. 収益化の2ルートを数字で潰す

登録者は **2,910人**で、要件の1,000人は**すでに満たしている**。残る関門は片方だけ。

### ルートA: ショート1,000万回 / 90日 — **算術的に閉じている**

```
直近90日 shorts        802.78 h    105,761 views
直近30日 shorts        762.12 h    101,245 views
```

105,761 / 10,000,000 = **1.06%**。**約94.6倍**足りない。
1本あたりの中央値1,344で割ると、90日で **7,440本＝1日82.7本**が必要になる。
最盛期（2025年10月）の1本あたり5,454で計算しても1日20本。

**これは努力量の話ではない。このルートは選択肢から外してよい。**

### ルートB: 有効な総再生時間 4,000時間 / 365日 — **唯一残っている**

```
直近365日 videoOnDemand   0.08 h    9 views
```

4,000 h / 365日 = **1日あたり 10.96時間**の「ショート以外」の再生時間が要る。

一方でショートは**1日あたり25.4時間**の再生時間をすでに生んでいる（762.12h ÷ 30日）。
**視聴の総量は要件の2.3倍あり、入っている箱が違うだけ。**
既存の注意のうち **43%を長尺・ライブ側に移せれば要件を満たす**。

これがライブ配信（`docs/superpowers/specs/2026-09-09-live-streaming-design.md`）の
狙いと一致する。**その前提が正しいかは 2026-09-12 以降にしか分からない。**

## 5. 現行フォーマットは、旧フォーマットの1/4しか取れていない

公開直後の窓を揃えて比べた（どちらも約59秒のショート）:

| | 本数 | 再生 中央値 | 平均視聴率 中央値 |
|---|---|---|---|
| 2025年10月公開（窓 10/01〜11/30） | 69 | **5,454** | **95.3%** |
| 2026年8月公開（窓 08/12〜09/10） | 41 | **1,315** | **69.0%** |

再生の差 4.1倍は**高市政権発足という当時の需要**で説明が付く（交絡している）。
しかし **平均視聴率 95.3% → 69.0% は題材の需要では説明が付かない。**
どちらも同じ尺・同じ縦型で、**見始めた人が最後まで見るかどうか**の差である。

30日窓・200再生以上の51本で、視聴維持率と再生数の相関は **r = 0.65**（前回 r=0.67 と一致）:

| | 平均視聴率 中央値 | 再生 中央値 |
|---|---|---|
| 上位半分（n=25） | 87.5% | **1,776** |
| 下位半分（n=25） | 58.8% | 1,263 |

**冒頭の維持を旧フォーマット水準に戻すだけで、同じ本数で約1.4倍。**

### 5-1. 検定に至らなかった仮説（記録のみ）

見出しが「項目の列挙」型かどうかで分けた:

| | 本数 | 再生 中央値 | 平均視聴率 中央値 |
|---|---|---|---|
| 列挙型（`120の政策を読む` `264項目を読む` など） | 5 | 1,424 | **58.8%** |
| それ以外 | 46 | 1,330 | 71.7% |

**維持率は下がるが再生数は下がっていない**（1,424 vs 1,330）。n=5 で、
CLAUDE.md の「実例1件で門番の語彙を増やさない」に照らしても**採用しない**。
数件たまってから再測する。

沖縄県知事選シリーズ（8本）は 1,433 / 73.7% で、それ以外（43本）の 1,316 / 70.5% と
**差が無い**。シリーズ化による上積みも下押しも観測されていない。
