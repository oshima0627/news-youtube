# アナリティクス調査 — 2026-09-07

対象期間 **2026-08-12 〜 2026-09-07**（現行パイプラインで作った動画が出始めた日から）。
取得は YouTube Analytics API v2 と Data API v3。`scripts/retention_report.py` と
同じ認証（`upload_youtube.get_credentials()`）を使い、**投稿は一切していない**。

前回の観測は `scripts/retention_report.py` の docstring（2026-08-27）にある。
本書はそれを**更新する**もので、成立しなくなった結論もある。

## 0. 先に — この調査中に踏んだ計測の罠

**動画別レポートは、日別レポートと合わない状態で返ってくることがある。**

同じ問い合わせを約20分あけて2回投げた結果:

| | 1回目 | 2回目（以降3回とも同じ） |
|---|---|---|
| 日別（`dimensions=day`）の合計 | 93,001 | 93,001 |
| 動画別（`dimensions=video`）の合計 | 93,013 | **89,415** |
| `hQm4LqOv18o` の再生 | 2,643 | **477** |
| `Awg7xxgeVJ4` の再生 | 997 | **59** |

減った 3,586 は **2026-08-31 の日別再生 3,598 とほぼ一致**する。実際、2回目以降は
動画別に `filters=video==` を付けて日別に割ると **08-31 の行だけが全動画から消えている**。
日別合計は動いていないので、データが消えたのではなく**動画別への割り当てが一時的に欠けている**。

**したがって `retention_report.py` の数字は、単体では信用できない。**
比較に使う前に、日別合計と動画別合計が一致するかを見ること。
本書の再生数は**1回目（欠けの無い側）**を使っている。

## 3. 決めているのは冒頭12秒

視聴維持率と再生数の相関は **r = 0.67**（n=43）。ただし「維持率が高いと伸びる」
より正確な言い方は、**冒頭で落ちなければ伸びる**である。

12秒地点（動画の20%）の残存率で3等分すると:

| | 本数 | 12秒残存 中央値 | 再生 中央値 |
|---|---|---|---|
| 下位 | 14 | 69% | 1,236 |
| 中位 | 15 | 92% | 1,324 |
| 上位 | 14 | **110%** | **1,862** |

3秒地点（5%）の残存率だけでも相関は **r = 0.67** で、維持率全体と同じ。
**冒頭3秒の時点で結果はほぼ決まっている。**

実際の残存曲線（`audienceWatchRatio`。100%超はループ再生）:

| 動画 | 5% | 15% | 20% | 50% | 100% |
|---|---|---|---|---|---|
| 消費税1%で4.3兆円（14,379再生） | 216% | 180% | 167% | 148% | **124%** |
| 古謝氏の公約（2,527再生） | 152% | 112% | 100% | 71% | 60% |
| 個人情報の漏えい（997再生） | 122% | 87% | 76% | 46% | 25% |
| SNS年齢確認（1,189再生） | 111% | 55% | **46%** | 27% | 13% |

**落ちる場所は全部が冒頭**で、50%地点以降の傾きは勝ち負けでほとんど変わらない。
勝った動画は最後まで平ら（=最後まで見てもう一度見る）。

`uploadStatus=processed`、年齢制限も地域制限も無い。制作側の欠陥は見つからなかった。
**原因は特定できていない。**（43本中2本＝約5%）

### 5-2. 長尺は依然として動いていない

`UqjB--sNTKk`（8/20公開・4分15秒）は **累計5再生**。流入は
`SHORTS_CONTENT_LINKS` の5だけで、検索・関連動画からは0。
8/20以降、長尺は1本も作られていない。**前回の結論（乗る面が無い）は変わらない。**

### 5-3. `published.json` に存在しない動画のエントリがある

`2D_cpARVcw0`（8/13 18:30 の枠）は `videos.list` で引けない＝**チャンネルに無い**。
`docs/known-issues.md` 8番の「`published.json` から消えた動画のエントリを外す」に
あたるケース。**本書では触っていない。**

### 5-4. 07:30 の枠が 9/3 以降 空いている

9/3〜9/11 は **18:30 の選挙動画だけ**（9/7〜9/11 の5本は予約済みを API で確認）。
1日2本が1本になっている。直近の日別再生の目減りには、この本数減も効いている。
