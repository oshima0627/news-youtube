# 題材の候補 — 2026-09-07

`docs/analytics-2026-09-07.md` の実測を踏まえて、候補の検索語 **32語を採用ゲート
（`evidence.collect`）に実際に当てた**結果。国会会議録APIだけを叩いており、
**動画は1本も作っていない**。

## 先に — 採用ゲートは題材の選別に使えない

32語のうち **31語が「採用可」で返ってきた**（1語以上の根拠が取れた）。
落ちたのは `NHK 受信料` の1語だけ。

これは壊れているのではなく、CLAUDE.md の「未解決」に書いてあるとおりの挙動である。
ゲートが見ているのは**検索語が同じ文脈に2語以上固まって現れるか**だけで、
引用が見出しを裏付けているかは判定していない。実例:

> `携帯電話 料金` — 採用可13件。1位の引用は
> **「高いもので、二万何千円の料金で売りますと。転売。……航空法、審議に入れるか」**
> （2025-05-07 衆院国土交通委）。**航空券の転売の話**で、携帯料金とは無関係。

**したがって「ゲートを通ったか」で題材を選んではいけない。**
以下は、通った31語の引用を実際に読んで選び直したものである。

## 選ぶ基準（アナリティクスから）

| 基準 | 根拠 |
|---|---|
| **カネ（税・負担・補助金）か対外関係** | 税 n=4 で再生中央値 2,991、対外 n=2 で 3,164。全体の中央値は 1,324 |
| **具体的な金額・件数が引用の中に逐語である** | 冒頭12秒の残存率が結果をほぼ決める。数字は冒頭に置ける |
| **発言が新しい（2026年）** | 「今の話」として成立しないと冒頭で切られる |
| **発言者に ja.wikipedia の記事画像がある** | 写真あり n=24 は再生中央値 1,560・12秒残存100%、代替画像（国会議事堂）n=19 は 1,263・84%。ただし題材の大きさと交絡している |

視聴者は **55歳以上が74.5%・男性85.4%**。相続・医療費・年金・領土が刺さる層である。

## 使うとき

07:30 の枠が 9/3 以降 空いている。台本は対話セッションが書いて渡す:

```bash
python scripts/run_daily.py --keyword "復興特別所得税 防衛" --script <台本.json> --days-ahead 1 --limit 1
```

- **`--script` を渡す前に、上の引用が出典URLに逐語であることを自分で確かめる。**
  ここに挙げた引用は `evidence.collect` が切り出した本文そのままだが、
  台本に書き写す段で崩れると `ground_excerpt` に落とされる
- **台本を書いたら `check_telop.py` で幅を測ってからビルドする**
- **9/13（投票日当日）は投稿しない**（公職選挙法129条）
- ここに挙げた検索語は、直近14日の `state/used.json` と2語以上かぶらないことを
  確認済み（`個人情報 漏えい` だけがかぶるので候補から外してある）
